# Issue tracker: GitHub

Issues and specs for this repo live in GitHub Issues at `flowgrow/framer-kit`. Use the `gh` CLI from this repository to create, read, list, comment on, label, and close issues.

## Pull requests as a triage surface

PRs as a request surface: no.

## Skill instructions

- “Publish to the issue tracker” means create a GitHub issue.
- “Fetch the relevant ticket” means read the issue and its comments with `gh issue view <number> --comments`.
- Resolve a bare `#number` as an issue or PR before acting on it.
- For parent and child work, use GitHub sub-issues when available; otherwise link issues in their bodies.
- For blocking work, use GitHub issue dependencies when available; otherwise record `Blocked by: #<number>` in the child issue.
